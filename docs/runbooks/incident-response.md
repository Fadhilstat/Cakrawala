# Incident Response

1. Disable the affected provider or private feature.
2. Rotate any credential that may have been exposed.
3. Preserve logs and payload hashes without copying secrets into an issue.
4. Identify the earliest affected ingestion or deployment.
5. Quarantine suspect data and stop model promotion.
6. Restore service only after a regression test covers the failure mode.
7. Document the incident and the preventive control that was added.
